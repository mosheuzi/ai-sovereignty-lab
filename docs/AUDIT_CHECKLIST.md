# Source Audit Checklist

Use this checklist for every source before a claim is promoted into a reviewed dataset release.

## Source identity

- [ ] Source ID is unique
- [ ] Publisher is correctly named
- [ ] Publication or update date is recorded
- [ ] URL resolves
- [ ] Source type is classified
- [ ] Primary source is used when available

## Claim support

- [ ] Exact supported claim is written in plain language
- [ ] Numeric value matches the source exactly
- [ ] Unit and time period are recorded
- [ ] Approximate, minimum, maximum and forecast values are labeled
- [ ] Operational and planned capacity are separated
- [ ] Conditional or non-binding status is recorded
- [ ] Unsupported interpretations are listed

## Sovereignty classification

- [ ] Physical location is recorded
- [ ] Operator is recorded
- [ ] Ownership countries are recorded
- [ ] Applicable jurisdictions are recorded
- [ ] Operational control is assessed
- [ ] Legal and governance control is assessed
- [ ] Supply-chain control is assessed
- [ ] Local hosting is not confused with domestic ownership

## Graph impact

- [ ] Supported node or edge IDs are listed
- [ ] Dependency direction is correct
- [ ] Criticality and substitutability are justified
- [ ] Direct observation and analytical inference are separated
- [ ] Downstream claims are not broader than the evidence

## Review

- [ ] Audit date is recorded
- [ ] Reviewer is recorded
- [ ] Next review date is assigned
- [ ] Required dataset action is explicit
- [ ] Known uncertainty remains visible
