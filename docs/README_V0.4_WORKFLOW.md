# v0.4 Research Workflow

1. Audit a small source batch.
2. Record exact supported claims and unsupported extensions.
3. Add required corrections to the research log.
4. Update the human-readable methodology when a recurring ambiguity appears.
5. Consolidate corrections into a reproducible dataset build.
6. Run structural validation.
7. Request domain review.
8. Merge only after the audit findings and dataset changes agree.

The source-audit files are intentionally separate from the canonical v0.3 archive. This avoids silently changing the public research snapshot while the audit is still in progress.
