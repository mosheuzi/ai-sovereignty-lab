# Execution Plan

## Phase 0: Repository bootstrap

- Create the public GitHub repository `ai-sovereignty-lab`
- Commit the dataset, source catalogue and planning documents
- Mark the repository clearly as a research draft
- Add data validation before UI implementation

Exit condition: a clean public research repository with a documented dataset and roadmap.

## Phase 1: Research

- Audit all source URLs and exact claims
- Review the definition of sovereignty
- Complete Israel and United States first
- Expand China, East Asia, Europe, Gulf and India
- Add evidence-backed scenarios
- Produce dataset v0.4

Exit condition: reviewed-release candidate data with documented gaps.

## Phase 2: Product and UX design

- Produce information architecture
- Create low-fidelity wireframes
- Define graph interactions
- Define status and ownership visual language
- Test whether users understand the distinction between local presence and national control
- Define mobile behavior

Exit condition: approved MVP specification.

## Phase 3: Front-end MVP

- Create Vite, React and TypeScript project
- Load static dataset
- Implement capability matrix
- Implement graph filtering
- Implement evidence drawer
- Implement ecosystem comparison
- Implement dependency-removal scenarios
- Add source links and download option
- Add responsive layout and accessibility support

Exit condition: working Vercel preview usable by reviewers.

## Phase 4: Review and hardening

- Factual review
- UX review
- Accessibility review
- Performance review
- Mobile testing
- Broken-link validation
- Data-schema validation
- Clear disclaimer and research status

Exit condition: approved public beta.

## Phase 5: Open-source contribution launch

- Add contribution templates
- Add issue templates for new evidence, corrections and new ecosystems
- Publish contribution standards
- Tag the first reviewed release
- Invite evidence-backed contributions

Exit condition: public beta, tagged dataset and active contribution workflow.

## Phase 6: Personal website integration

- Create `/labs/ai-sovereignty` on mosheuziel.com
- Add a concise research introduction
- Embed or mount the standalone app
- Add contribution and methodology links
- Add structured metadata and social preview
- Publish an accompanying LinkedIn post and article entry

Exit condition: the application is accessible as a first-class interactive research asset on the personal website.
