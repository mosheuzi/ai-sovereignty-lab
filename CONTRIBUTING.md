# Contributing

This project welcomes evidence-backed corrections, additional sources, new ecosystem research and improvements to the analytical model.

The repository is public from its research-draft stage so that the evidence, assumptions and gaps remain visible. Current data should not be treated as authoritative until it reaches a tagged reviewed release.

## Contribution types

- Correct an existing claim
- Add or replace a primary source
- Add a missing national capability
- Improve a dependency relationship
- Add a new ecosystem
- Improve the front-end or accessibility
- Propose a scenario for the dependency explorer

## Evidence standard

A contribution that changes research data should include:

1. The exact claim being added or corrected
2. A primary-source URL when available
3. Publication date
4. Whether the claim is operational, planned, conditional or analytical
5. The relevant node or edge
6. Any important limitation or uncertainty

## Pull-request rule

Data changes and UI changes should normally be submitted in separate pull requests so factual review can be performed independently from design review.

## Tone

The project is exploratory. Contributions should focus on evidence and transparent assumptions, not national rankings or promotional claims.
